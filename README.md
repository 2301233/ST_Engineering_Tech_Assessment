How to Set Up:
1. Open up command prompt in root folder of this project
2. Run docker-compose up --build
3. Click on http://localhost:5173 to access the CSV Upload Website

How to Run:
1. Click on the "Choose file" button to select CSV file
2. Select the data.csv file in the root folder of this project
3. Click on the "Upload CSV" button to upload selected CSV file
4. Use search text box in each column to filter out the data you want
5. Click on the "Next" button to go to the next page in the data table
6. Click on the "Previous" button to go to the previous page in the data table
7. Enter the page number you want to go in the text field beside the "GO" button before clicking "GO" to load that page of the data table
